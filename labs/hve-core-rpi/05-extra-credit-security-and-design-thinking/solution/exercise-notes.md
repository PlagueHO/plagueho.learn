# Optional Copilot CLI exercise notes

Useful Security output should:

- Scope findings to `src/pages/api/apply.ts`.
- Cite source evidence.
- Separate confirmed vulnerabilities from defensive recommendations.
- Avoid exposing sensitive request data.

Useful Design Thinking output should:

- Identify the user and their job to be done.
- Replace the vague dashboard request with a testable problem statement.
- Record assumptions that need research.
- Hand the refined problem to RPI without implementing it.

These are comparison criteria, not fabricated plugin output.
