# HVE principles map

Use this recovery aid to check the discussion, not to replace it.

| RPI phase | Primary question | Evidence produced |
|-----------|------------------|-------------------|
| Research | What is true in this repository and problem space? | Sources, constraints, patterns, and open questions |
| Plan | What change should be made, in what order, and why? | Scoped phases, decisions, file targets, and validation commands |
| Implement | Does the bounded change work as planned? | Code, tests, validation output, and a changes log |
| Review | Does the result satisfy the plan without regressions? | Findings, discrepancies, and follow-on actions |

HVE is the methodology. HVE-Core is one opinionated, rapidly evolving implementation of that methodology.
