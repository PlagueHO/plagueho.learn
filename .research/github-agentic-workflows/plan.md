# Research Plan: GitHub Agentic Workflows

## Topic & Boundaries

**Topic**: GitHub Agentic Workflows — principles, architecture, and practical application for building AI agents that can autonomously execute tasks using tools and reasoning.

**Scope**: High-level introduction suitable for a 8-slide presentation outline for GitHub DevDays 2026 workshop. Focus on:
- What agentic workflows are and why they matter
- Core principles and how they differ from traditional automation
- Practical examples and use cases
- How to integrate with GitHub Copilot and development tools
- Getting started patterns for workshop participants

**Out of scope**: Deep implementation details, advanced reasoning algorithms, model training.

## Purpose & Target Audience

**Purpose**: Support creation of an 8-slide presentation outline for a GitHub DevDays 2026 workshop introduction.

**Target Audience**:
- Software developers (entry-level to mid-level experience with AI/ML)
- Platform engineers interested in agent-based automation
- GitHub Copilot users exploring advanced capabilities
- Workshop participants (hands-on learners)

**Desired Outcomes**:
- Presentation outline maps research findings to each of 8 slides
- Includes concrete examples from GitHub's workshops and community
- References available workshop exercises and follow-up resources
- Emphasizes "why use agentic workflows" before deep technical details
