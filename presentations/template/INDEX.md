## Template Slide Index

Use this table to map sections in an OUTLINE.md file to the most suitable slide type in presentations/template/slides.md.

| Slide | Template Slide Type | Brief Description | Use This When OUTLINE.md Says | Best For |
| --- | --- | --- | --- | --- |
| 1 | Title Hero | Full-screen opening slide with title, subtitle, presenter metadata, and theme badges. | Title slide, session framing, opening context | Establishing talk identity and tone |
| 2 | About Me (VS Code Card) | Presenter profile rendered in a VS Code-style card layout. | About me, speaker intro, credibility setup | Personal intro and audience connection |
| 3 | Agenda Cards | Multi-card agenda with optional demo pills and section links. | Agenda, session map, what we will cover | Navigation and pacing setup |
| 4 | Banner Content | General-purpose content slide with top banner, bullets, and callout. | Standard content, concept explanation, context slide | Most narrative sections |
| 5 | Before/After Comparison | Two-column comparison with explicit old vs new framing. | Before and after, legacy vs modern, trade-off comparison | Contrasting approaches |
| 6 | Evolution Strip | Thought bubble plus staged progression strip and maturity arrow. | Evolution, maturity model, progression levels | Showing capability growth over time |
| 7 | Three Pattern Cards | Three option cards for patterns or architecture choices. | Patterns, options, decision alternatives | Option comparison and recommendation |
| 8 | Product Pillar Grid | Branded three-pillar product/service capability grid. | Pillars, platform components, capability areas | Product framing and service breakdown |
| 9 | Pyramid Stack | Layered architecture stack with supporting cards. | Layers, stack, dependency levels, hierarchy | Architecture layering and sequencing |
| 10 | Tools and Resources Grid | Linkable tool/resource cards plus full-width supporting card. | Tools, references, links, ecosystem slide | Resource roundups |
| 11 | Workflow Pipeline | Horizontal process flow with supporting detail cards and callout. | Process, workflow, lifecycle, operating model | End-to-end execution flow |
| 12 | 2x2 Overview Grid | Four section cards for thematic overview. | Four pillars, key domains, grouped topics | High-level thematic summaries |
| 13 | Demo Title Slide | Dramatic demo transition slide with checklist and timing. | Demo handoff, live walkthrough intro | Framing and scoping a demo |
| 14 | Governance Grid | Three governance columns plus good/bad examples and warning callout. | Guardrails, governance, standards, do/don't | Policy and quality controls |
| 15 | Code and Terminal Panels | Side-by-side code and terminal output with syntax highlighting. | Code walkthrough, command output, implementation details | Technical deep dives |
| 16 | Hero Quote | Single insight or quote with focused visual emphasis. | Key insight, strong statement, framing quote | Emphasis and memorable moments |
| 17 | Action Grid | Three next-step action cards in a bold visual frame. | What to do now, action plan, implementation steps | Closing actions and enablement |
| 18 | Key Takeaways | Numbered takeaway list with progressive reveal. | Summary, top lessons, recap | Consolidating learning points |
| 19 | Mermaid Diagram | Centered Mermaid diagram area with supporting callout. | Architecture diagram, dependency map, flow chart | Visual systems explanation |
| 20 | Magic Move Code Evolution | Animated multi-step code transformation using magic-move. | Refactor journey, iterative code changes, evolution demo | Showing code change over time |
| 21 | Thank You / Q&A | Closing slide with links and call-to-action block. | Q&A, close, follow-up links | Session wrap-up |

## Selection Notes

- Start by tagging each OUTLINE.md slide with intent: opening, explain, compare, process, demo, summarize, or close.
- Pick the template row that matches intent first, then adapt visual details.
- Reuse Slide 4 (Banner Content) as the default fallback when no specialized pattern is needed.
